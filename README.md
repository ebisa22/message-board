# Message Board

A simple message board built with Express.js and EJS as part of The Odin Project.

## Features

- View messages posted by users.
- Add a new message by providing a username and message text.
- Delete messages from the message board.
- Navigate between the home page and the new message form.

## Technologies Used

- Node.js
- Express.js
- EJS
- HTML
- CSS

## Getting Started

1. Clone the repository.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run build
   ```

4. Open `http://localhost:8080` in your browser.

## Purpose

This project was built to practice Express routing, controllers, EJS templates, form handling, and basic server-side functionality.
